# Delivery platform logos

Drop the official partner logos here with **exactly these filenames**.
index.html will reference them by name.

| Filename | Platform | Notes |
| --- | --- | --- |
| `just-eat.svg` | Just Eat | White / light version |
| `deliveroo.svg` | Deliveroo | White / light version |
| `uber-eats.svg` | Uber Eats | White / light version |

## Get the light versions

The order section sits on dark navy, so the **white or light** variant of
each logo is the one to download. The standard dark-on-white version will
be almost invisible there.

Each platform publishes official assets for restaurants — search for
"Just Eat partner brand assets", "Deliveroo restaurant hub logo",
"Uber Eats partner toolkit". Using their supplied artwork to link to your
own listing is what these kits are for.

## Format

**SVG is best** — it stays sharp at any size and weighs almost nothing.
PNG with a transparent background is fine too; if PNG, name them
`just-eat.png` etc. and tell me, and I will adjust the markup.

Avoid JPG: it cannot do transparency, so the logo arrives in a white box
on a navy background.

## Uploading

github.com → this repo → the `logos` folder → **Add file → Upload files**
→ drag them in → commit. Then tell me and I will wire them into the
cards, keeping the brand-coloured spine as the frame.
